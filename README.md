# Flappy Bird — Sky Challenge

Game Canvas vanilla HTML/CSS/JavaScript tanpa aset atau dependensi eksternal. Musik latar chiptune bernuansa ceria akan diputar saat permainan dimulai dan dapat diatur lewat **Settings > Music**. Kumpulkan koin di antara pipa untuk membuka skin burung melalui **Shop Skins** pada Home.

## Menjalankan

Buka `index.html` langsung di browser modern. Tekan **Play**, lalu klik/tap, `Space`, atau `Arrow Up` untuk flap. `P` atau `Esc` untuk pause.

High score dan pengaturan tersimpan lokal pada browser melalui `localStorage`.
