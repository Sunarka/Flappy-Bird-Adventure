# 🎵 Flappy Bird Adventure - Audio Directory

Folder ini berisi file soundtrack audio game yang dapat diputar secara otomatis di dalam game maupun di menu Shop:

## 📂 File Audio Soundtrack Anime:
1. `gurenge.wav` - **Demon Slayer Opening 1 (LiSA - Gurenge)**
2. `blue_bird.wav` - **Naruto Shippuden Opening 3 (Ikimonogakari - Blue Bird)**
3. `we_are.wav` - **One Piece Opening 1 (Hiroshi Kitadani - We Are!)**
4. `sparkle.wav` - **Your Name / Kimi no Na wa (RADWIMPS - Sparkle)**

## 💡 Kustomisasi Audio:
Anda dapat menimpa file audio di folder `audio/` ini dengan file audio asli yang Anda sukai. Sistem game akan otomatis memutarnya secara mulus saat lagu tersebut dipilih di Shop atau saat bermain!
